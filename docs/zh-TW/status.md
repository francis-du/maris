# 發布進度

Maris 仍在開發中。下面的清單與發布檢查共用資料，分別記錄實作、自動測試和真實裝置測試。

## 發布前需要完成 {#scope}

未完成項目包含功能、安裝、介面、文件和已回報的問題。新增問題也必須檢查，不能刪除清單項目來提前發布。

## 自動測試 {#checks}

測試涵蓋音訊處理、設定儲存、鍵盤與滑鼠、復原和安裝。200 輪檢查使用不同的測試資料，輪流執行相關測試；不是 200 次完整審查，也不能取代試聽。修改程式後需要重新驗證，跳過或中斷的測試不算通過。

## 裝置和安裝包 {#native}

macOS、Windows 和 Linux 必須各自執行建置與測試。耳機、喇叭、藍牙、裝置斷線和插拔電源也需要實際檢查。正式安裝包需通過對應版本的測試、裝置檢查、授權審查和簽章確認。一般線上安裝不接受開發候選包。

## 正式發布 {#publication}

提交原始碼、自動建置、更新網站和發布應用程式是不同操作。上傳成功不代表測試全部通過或安裝包已可下載。維護流程見[建置與發布](../development/releasing.md)。
