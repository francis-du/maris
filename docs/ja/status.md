# 公開状況

Maris は開発中です。下の一覧は公開前のチェックと同じデータを使い、実装、自動テスト、実機テストを分けて記録します。

## 公開前に必要な作業 {#scope}

機能、インストール、画面、説明書、報告された不具合が対象です。新しい問題も確認します。一覧から項目を消して公開を早めることはできません。

## 自動テスト {#checks}

音声処理、設定の保存、キーとマウス操作、取り消し、インストールを確認します。200 ラウンドは異なるテストデータと関連テストの組み合わせで、200 回の完全な審査ではありません。試聴も別に必要です。コード変更後は再実行し、スキップや中断は合格に数えません。

## 機器とインストール用パッケージ {#native}

macOS、Windows、Linux ごとのビルドとテストが必要です。ヘッドホン、スピーカー、Bluetooth、機器の切断、電源の接続・取り外しは実機でも確認します。公開用パッケージには、その版のテスト、機器確認、ライセンス審査、署名確認が必要です。通常のインストーラーは開発候補版を受け付けません。

## 公開 {#publication}

ソースの送信、ビルド、ウェブサイト更新、アプリ公開は別の操作です。送信成功だけでは、テスト合格やダウンロード開始にはなりません。手順は[ビルドと公開](../development/releasing.md)を参照してください。
